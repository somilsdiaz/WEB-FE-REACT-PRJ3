## 🚀 Features

- **Client Management**
  - Create, view, update and delete client profiles
  - Track client status and contact information
  - Manage multiple contacts per client
  - Detailed client history and analytics

- **Opportunity Tracking**
  - Create and manage business opportunities
  - Track opportunity status and progress
  - Monitor estimated values and closing dates
  - Conversion rate analytics

- **Follow-up Management**
  - Schedule and track follow-up activities
  - Record interaction details and notes
  - Contact history tracking
  - Email integration

- **Analytics Dashboard**
  - Real-time key metrics visualization
  - Client value analysis
  - Opportunity pipeline charts 
  - Business line distribution graphs
 
## 🛠️ Technology Stack

- **Frontend Framework:** React 18
- **Language:** TypeScript
- **Build Tool:** Vite
- **UI Components:** 
  - Material-UI
  - Tailwind CSS
  - Shadcn/ui
- **Charts:** Recharts
- **State Management:** React Query
- **Routing:** React Router
- **HTTP Client:** Axios

## Installation

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/somilsdiaz/WEB-FE-REACT-PRJ3
    cd WEB-FE-REACT-PRJ3
    ```
2.  **Install dependencies:**

    ```bash
    npm install
    ```
3.  **Start the development server:**

    ```bash
    npm run dev
    ```
